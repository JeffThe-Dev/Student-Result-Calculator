# Student Result Calculator

A simple Student Result Calculator built using Python.

## Features

- Takes the student's name as input.
- Accepts marks in six subjects.
- Validates marks (0–100).
- Handles invalid inputs using try/except.
- Calculates total marks.
- Calculates overall percentage.
- Assigns grades based on percentage.
- Determines pass/fail status.

## Subjects

- Physics
- Mathematics
- Computer Science
- Pakistan Studies (PST)
- Urdu
- English

## Grading System

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| 40–49.99% | E |
| Below 40% | F |
